# Kubico

App para gerir tudo o que é de casa: famílias com várias contas, calendário partilhado, tarefas, listas de compras, equipamentos e casa inteligente.

> "Cubico" é como se diz casa em Angola.

## Stack

- **Backend**: ASP.NET Core, SignalR, PostgreSQL (EF Core)
- **Apps**: Flutter (Android, iOS, Windows, macOS, web)

## Estado

Em arranque. A primeira entrega é uma fatia vertical: contas e agregados, e uma lista de compras partilhada em tempo real.
